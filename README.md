# SmartCity-IoT-Management-System

## Overview

A modular IoT management system for smart cities to manage devices, collect sensor data in real-time, and send alerts. Exemplifies scalable architecture and advanced software engineering techniques.

## Features

- Device registration and management
- Real-time sensor data ingestion
- Event-driven alerting system
- Data visualization web dashboard
- Automated testing and CI/CD pipeline included

## Technologies

FastAPI, React, PostgreSQL, MQTT, Kafka, Pytest, GitHub Actions

## Getting Started

1. Clone the repo
2. Install dependencies in backend and frontend
3. Run both services (instructions in documentation)
4. Access the dashboard at `http://localhost:3000`
